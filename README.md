# 2D横スクロールアクションゲーム (C++)

C++だけで動く、シンプルな **2D横スクロールアクションゲーム（ターミナル版）** です。

- 左右移動: `A / D`
- ジャンプ: `W / Space`
- 終了: `Q`
- コインを取るとスコア加算
- 敵に触れる、または落下でリスポーン

## 使用技術

- C++17
- 標準ライブラリ + POSIX端末制御 (`termios`, `select`)
- CMake

## ビルド

```bash
cmake -S . -B build
cmake --build build
```

## 実行

```bash
./build/side_scroller
```

## コードの入口

- `src/main.cpp`

ゲームロジック（重力、当たり判定、カメラ追従、敵の往復移動）は1ファイルにまとめています。
まずはプレイヤー速度やジャンプ力の定数を変更すると、ゲームバランス調整の練習になります。
